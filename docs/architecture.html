Inventory Management System

System Architecture

Factory inventory demo — Vue 3 + FastAPI + in-memory JSON data

Tech Stack

Frontend :3000

Vue 3 Composition API Vite Vue Router Axios

SPA with 6 route-level views, a shared FilterBar, composable-based global state, and SVG/CSS-grid data visualization. Supports EN/JA localization.

Backend :8001

Python 3.14 FastAPI Uvicorn Pydantic v2

REST API with 14 endpoints. JSON files loaded once at startup; all filtering done in-memory. Swagger UI available at /docs.

Data Layer

JSON files In-memory No database

7 JSON files in server/data/ act as the data source. All mutations are non-persistent — data resets on server restart.

Key Design Patterns

Filter Singleton

Module-level refs in useFilters.js act as singleton state — all components share the same reactive filter values without a store like Pinia/Vuex.

Raw vs Derived

Raw data lives in ref() arrays. All display values (totals, percentages, status counts) live in computed() properties for automatic cache invalidation.

In-Memory Filtering

No SQL — Python list comprehensions filter the in-memory arrays on every request. Month filter supports both exact months (2025-01) and quarter aliases (Q1-2025).

i18n via Composable

useI18n() wraps locale JSON files. useAuth() returns language-aware user data. Locale persists to localStorage across sessions.
