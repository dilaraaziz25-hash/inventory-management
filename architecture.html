Overview

Full-stack demo of a factory inventory management dashboard. A Vue 3 single-page app talks to a FastAPI service over a REST API. There is no database — the backend loads seven JSON files from server/data/ into memory at startup and applies filtering on each request. State on the client is held in plain Vue refs with a small set of composables; filter state is shared across views through a singleton composable rather than a state-management library.

Data Flow

User changes a filter on any page; the change propagates through a shared composable, into the API client, to FastAPI, into the in-memory data slice, and back out to the view.

client/src/components/FilterBar.vueUser selects a value in one of four dropdowns: time period, warehouse, category, or order status.
client/src/composables/useFilters.jsFilterBar is bound to refs in a singleton composable. Updating a ref updates the shared state that every view reads from.
client/src/views/*.vueThe active view detects the change and calls getCurrentFilters() to assemble query params (skipping any value equal to 'all').
client/src/api.jsAxios request fires against http://localhost:8001/api/... with the filter object serialized to a query string.
server/main.pyFastAPI route receives query params; apply_filters() and filter_by_month() narrow the in-memory list. Pydantic validates the response.
server/mock_data.pySource data was loaded from JSON at startup into module-level lists — no I/O on the request path.
client/src/views/*.vueRaw response is stored in a ref; computed properties derive aggregates (KPIs, status counts, fill rate) and the template re-renders.

Filter System

Four global filters are shared across every view through useFilters.js. Each ref defaults to 'all'; values equal to 'all' are stripped from the outgoing query string. The inventory endpoint ignores month because stock has no time dimension.

Time Period month / quarter / all Warehouse warehouse / all Category category / all Order Status status / all
